# **App Name**: DocuSmart AI

## Core Features:

- User Accounts & Workspaces: Secure user authentication and workspace creation, enabling personalized document management.
- Workspace Folders: Organize documents efficiently within workspaces using a hierarchical folder structure.
- Document Upload: Enable secure document uploads (PDF, Word, Excel, CSV, TXT) to specified workspaces.
- Document Intelligence: AI powered document analysis tool: converts document into JSON for quering and extracts structured data from uploaded documents.
- Document Sharing: User level permissioning to enable team members secure collaboration. Permissions configurable at the document level.
- Chat with Documents: Interactive tool powered by AI that enables answering of questions, extraction of data and key insights, summarizing of data in document using AI.
- Mobile Friendly UI: UI optimized for mobile to maintain usability on all platforms. Chat interface is similar to standard SMS, WhatsApp applications.

## Style Guidelines:

- Primary color: A calm, professional blue (#4A8FE7), suggesting trust and efficiency.
- Background color: Light gray (#F0F4F8), to reduce eye strain during prolonged document interaction.
- Accent color: Soft green (#73CA5F), used for confirmations and positive actions.
- Body font: 'Inter' (sans-serif), chosen for its modern, neutral legibility in digital environments.
- Headline font: 'Space Grotesk' (sans-serif), for headlines and short amounts of body text. If longer text is anticipated, use 'Inter' for body.
- Minimalist, consistent icons from a standard library (e.g., Material Icons) representing file types and actions.
- Clean, card-based layouts for document previews, with clear visual hierarchy and ample whitespace.
